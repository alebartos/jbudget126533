# JBudget

Desktop personal budget manager written in Java with JavaFX, built as a university project at the University of Camerino.

## Features

- Income and expense tracking per person, with hierarchical tags
- Budgets, scheduled transactions, deadlines and amortization plans
- Dashboard and statistics views
- JSON file storage with automatic backups and a sync layer with conflict resolution
- GUI (JavaFX/FXML) and console views on the same model (MVC)

## Run

```bash
./gradlew run
```

Data is stored as JSON files in `Data/`.
